## 🏛️ About the Architecture

**[suwuyiku.pages.dev](https://suwuyiku.pages.dev)** is a meticulously crafted digital ecosystem and open-source web portfolio. Designed with an emphasis on high-end minimalism and a structural bento-box grid, it serves as the central routing hub for my creative units, scattered thoughts, and visual edits.

This repository houses the front-end codebase for the entire ecosystem. It operates with a "split architecture" strategy: utilizing GitHub as the primary vault for the MIT-licensed code, and Cloudflare Pages for lightning-fast, secure global deployment.

## 🧭 The Ecosystem Directory

Our site is structured to route visitors seamlessly through our creative and operational hubs:
* **About:** The origins and philosophy behind the delusion.
* **Fragments:** Scattered thoughts, media notes, and Notion API-powered transmissions.
* **Library:** An extensive manga and book archive.
* **Shop:** Curated community works and creator support channels.
* **Connections:** The official social directory and anonymous contact terminal.

## ⚙️ Technical Details

* **Hosting:** Cloudflare Pages (Main Engine) / GitHub Pages (Index Landing)
* **Framework:** Pure HTML5, CSS3, and Vanilla JavaScript.
* **Design Philosophy:** Minimalist UI/UX, responsive bento grid, and mobile-first navigation.
* **API Integrations:** Headless dynamic content fetching for seamless updates.
